My First Steps in Web Development

Published: September 2026

Why did I start learning web development?

  • I started learning web development because I wanted to understand how websites are built and how a simple idea can become a real and interactive website.
  • I was especially interested in creating websites from scratch instead of only using ready-made tools.

What did I learn first?

  • I started with HTML and CSS. HTML helped me understand the structure of a webpage, while CSS allowed me to control its appearance and layout.
  • I learned how to create headings, paragraphs, links, images, lists, forms, and navigation menus.

What was difficult for me?

At the beginning, understanding how different HTML elements work together was sometimes confusing. CSS was also challenging because small changes in properties such as display, margin, padding, and position could completely change the layout.
